## NLP Overview
### 1. Classification
```
   Input text ---> model --> predict something about the text
```
   Output can be:
   * [Sentiment extraction](./Sentiment_extraction.md)
   * Intent detection
   * Language detection
   * Topic modeling

### 2. Multi Classification
```
   Input text ---> model --> detect manything within the text (labels words in the text)
```
   Output can be:
   * Part of Speech tagging
   * [Named Entity Recognition](./NER.md)
   * Dependency Parsing
   * Consistituency Parsing

### 3. Generation

```
   Input text ---> model --> Output text
```
   Application can be:
   * [Machine Translation](./translation.md)
   * Question Answering
   * Summarization
   * Text Generation
